## 2026-06-04

### Codex Reconnecting 循环问题修复

**问题现象**：Codex 执行任务时不断循环 `Reconnecting... 1/5` 到 `5/5`，一直无法正常响应。

**根本原因**：WebSocket 不走代理。Codex 默认优先使用 `wss://` WebSocket 协议与 OpenAI 服务器通信，但 WebSocket 流量绕过了系统代理（叶子VPN 127.0.0.1:29448），在国内网络环境下无法直接连接 OpenAI 服务器。Codex 连续尝试 5 次 WebSocket 连接（每次约15秒超时），全部失败后才 fallback 到 HTTP/SSE 模式，浪费约75秒。

**验证**：通过代理访问 `https://api.openai.com/v1/models` 返回 403 + `unsupported_country_region_territory`，确认 OpenAI 检测到请求来源是中国大陆。

**解决方案**：修改 `C:\Users\miaoh\.codex\config.toml`，添加 HTTP-only provider 配置，强制 Codex 跳过 WebSocket，直接走 HTTP/SSE：

```toml
model_provider = "chatgpt-http"

[model_providers.chatgpt-http]
name = "ChatGPT HTTP"
base_url = "https://chatgpt.com/backend-api/codex"
wire_api = "responses"
requires_openai_auth = true
supports_websockets = false
```

关键配置：`supports_websockets = false`，强制禁用 WebSocket。

**参考**：GitHub Issues openai/codex #22634, #19821, #24045, #14297, #13041；vaitk.com 和 weste.net 相关文章。
