## 2026-05-17

### Claude Code 重新安装
- C盘清理后 Claude Code 打不开（npm全局包被删 + HTTP代理干扰）
- 解决：直接 `npm install -g @anthropic-ai/claude-code`，装好 v2.1.143

### WorkBuddy vs ArkClaw 对比
- WorkBuddy：腾讯出品，云端+本地混合，能直接读写本地文件，多模型切换
- ArkClaw：字节火山引擎，纯云端SaaS，飞书深度集成，9.9元/月起

### Claude Code 实际配置
- settings.json 中所有模型均指向 DeepSeek v4 Pro（穿壳跑DeepSeek）
- 与 WorkBuddy 里使用的是同一模型

### "作弊方法"验证（CDP接管浏览器插件）
- Chrome CDP远程调试成功，但浏览器插件在C盘清理时被删，AI插件全无
- 该方法前提：浏览器内已有付费AI插件，用户不具备此条件，方案无效

### 视频剪辑能力
- 安装 moviepy：支持截取、拼接、加字幕/音乐、调速、水印、转格式、批量
- 不支持：拖拽时间线、逐帧调色、花字动画

### 当前关注
- 用户想用上更强模型（Claude Opus/GPT-5等），可选方案：API Key直连 / WorkBuddy切模型 / 聚合平台

### 我的能力 vs Claude Code（20:54 新增）
- 用户问：我和操作Claude Code干活有什么区别
- 结论：大多数情况下我自己干更快，因为我知道用户背景、能直接操作文件、能多模态
- Claude Code适合作为备胎，当用户想对比方案或习惯其交互时使用

### Claude Code配置实情（20:54 新增）
- settings.json 中所有模型均指向 DeepSeek v4 Pro：
  - ANTHROPIC_BASE_URL = https://api.deepseek.com/anthropic
  - 所有模型（Opus/Sonnet/Haiku）都映射到 deepseek-v4-pro
- 等于Claude Code穿壳跑DeepSeek，和WorkBuddy里用的是同一个模型
