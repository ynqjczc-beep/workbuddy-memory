## 2026-05-20

### 网络问题修复（YZ-VPN 系统代理）
- **问题**：浏览器无法上网，腾讯视频PC端正常；关机重启后反复出现
- **根因**：YZ-VPN 使用 sing-box，配置 `set_system_proxy: true` 每次启动强制接管 Windows 系统代理；上游代理服务器 `38.80.191.170:8888` (vless) 不稳定，导致非中国网站走代理超时
- **修复**：关闭 Windows 系统代理（ProxyEnable: 1→0）；修改 sing-box 配置 `set_system_proxy: true → false`（文件：`D:\VPN\YZ-VPN\resources\bin\win32-ia32\config.json`，两处）
- **遗留风险**：VPN更新可能覆盖config.json，如问题复发考虑添加启动后自动关闭代理的保险脚本
